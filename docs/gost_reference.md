# Карта ГОСТ: жизненный цикл разработки netaccess

Рабочая шпаргалка «этап → ГОСТ → документ → шаблон» на весь жизненный цикл.
Стадии создания АС — по ГОСТ Р 59793-2021 (аналог ГОСТ 34.601-90).
Документы для ВКР собираются в `vkr/skeleton.md` (Приложения 1–6), исходники документов — в `docs/`.

## Решения для проекта (Этап 1)

- Класс ИС: ИСПДн (обрабатывает персональные данные сотрудников — категория 4 «иные ПДн»)
- Уровень защищённости: **УЗ-3** (категория 4, < 100 000 субъектов, угрозы 3-го типа)
- Аутентификация: парольная (ИАФ.2/ИАФ.4); TOTP — перспектива
- Модель доступа: **ABAC** (роль = атрибут субъекта; согласует ИЗ «роль-ориентированный доступ»)
- Заказчик: ООО «АСЛАНАРТ», 30 сотрудников, модельный набор ресурсов
- Локализация: русский / английский (Qt Linguist)
